IPAM Backend API Spec (Node.js) — Firebase Parity (FULL)
Scope: Circuits, Providers, Sites, Regions, Locations, Racks, VLANs, VRFs, Prefixes, Subnets, IPs, Devices, Interfaces, Manufacturers, Platforms, Wireless

1. Global Rules (Apply to ALL endpoints)
Authentication
•	Authorization: Bearer <token>
•	user_id must be derived from token
Org Scoping
•	Header: X-Org-Id
•	LIST/GET → where(orgId == X-Org-Id)
•	UPDATE/DELETE → read first, if org mismatch return 403
Server Managed Fields
•	CREATE → orgId, user_id, createdAt, updatedAt
•	UPDATE → updatedAt only
Slug Uniqueness per Org
•	Providers, Sites, Regions, Racks, Manufacturers, Platforms
2. Prefixes / Subnets / IPs (Hierarchical Core IPAM)
Firestore Structure: prefixes/{prefixId}/subnets/{subnetId}/ips/{ipId}
Hierarchy Rules
•	Prefix → Subnets → IPs
•	Subnet must belong to Prefix CIDR
•	IP must belong to Subnet CIDR
•	Prevent duplicate IP in same Subnet
•	On Subnet create/delete → update prefix.children
•	IP list sorted ascending
Endpoints
•	POST /api/ipam/prefixes
•	GET /api/ipam/prefixes
•	PUT /api/ipam/prefixes/:id
•	DELETE /api/ipam/prefixes/:id
•	POST /api/ipam/prefixes/:id/subnets
•	GET /api/ipam/prefixes/:id/subnets
•	PUT /api/ipam/prefixes/:id/subnets/:subnetId
•	DELETE /api/ipam/prefixes/:id/subnets/:subnetId
•	POST /api/ipam/prefixes/:id/subnets/:subnetId/ips
•	POST /api/ipam/prefixes/:id/subnets/:subnetId/ips/batch
•	GET /api/ipam/prefixes/:id/subnets/:subnetId/ips
•	PUT /api/ipam/prefixes/:id/subnets/:subnetId/ips/:ipId
•	DELETE /api/ipam/prefixes/:id/subnets/:subnetId/ips/:ipId
Required Fields
•	Prefix: status, prefix, vrf, tenant, site, vlan, role
•	Subnet: subnet, status, vrf, tenant, site, vlan, role
•	IP: ip
